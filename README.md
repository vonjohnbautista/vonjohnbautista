## The developer

### I like making complicated workflows feel simple.

I'm **Von**, a developer who enjoys turning a rough idea into something people can actually use. My interests bring together **Zoho development, web interfaces, automation, and APIs**.

Some days that means writing Deluge. Other days, it's building a React widget, working through an Angular interface, or exploring what Python can do.

The part I enjoy most? When the pieces finally work together.

| 🛠️ Building | 🧠 Exploring | 💬 Happy to discuss |

| Zoho customisations and widgets | Python and backend development | Zoho applications and Deluge |
| React and Angular interfaces | Better application structure | Frontend development |
| Scripts and API integrations | Data tools and useful automation | Ideas, experiments, and lessons learned |

> **My kind of progress:** something works better today because of what I learned yesterday.

## Behind the commits

A few principles I try to bring to every project:

- **Understand first.** A good implementation starts with a clear problem.
- **Make it readable.** Future me is also a person who has to maintain this.
- **Keep the useful patterns.** Reuse what works and improve what doesn't.
- **Write down the essentials.** Setup instructions are part of the project.
- **Stay curious.** There's usually something to learn from the bug.
